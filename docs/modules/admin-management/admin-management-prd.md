# 管理员运营页面 PRD

## 状态与上下文

- 状态：已确认。
- 实现状态：页面及管理员商品查询 API 已实现；验证结果与剩余缺口见实施文档。
- 所属应用：前端 `apps/web`，需要补充后端管理员商品查询接口。
- 关联文档：[管理员运营设计](./admin-management-design.md)、[管理员运营 CRUD 契约](../../contracts/admin-management-crud-contract.md)。
- 最后更新：2026-11-07。

## 目标

为管理员提供一个受角色保护的运营入口，集中查看商品目录和订单履约状态，并完成整单发货。

## 已确认范围

| 能力     | 范围                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 商品查看 | 分页查看商品、SKU、价格、实物库存、可售状态、上下架状态和基础商品信息   |
| 订单查看 | 分页查看全部订单，按订单号、买家、状态筛选，查看订单详情和收货/物流快照 |
| 订单发货 | 对 `pending_shipment` 订单填写快递公司和运单号，提交整单发货            |
| 权限     | 仅启用的管理员账号可访问；普通用户不能进入页面或调用管理员接口          |
| 状态反馈 | 页面处理加载、失败、空数据、提交中、提交失败和成功后的刷新              |

## 明确不包含

- 商品编辑、上下架、价格修改、库存修改、商品删除。
- 订单代付、取消、改价、修改状态、拆单发货、退款和售后。
- 前端新增商品导入能力；继续使用现有内部 CLI。
- 实时物流轨迹、批量发货、批量操作和导出报表。

## 页面入口

管理员运营入口：

- `/admin/products`：商品目录页，支持搜索、筛选、分页和商品详情查看。
- `/admin/orders`：订单列表页，支持筛选、分页、详情查看和待发货订单发货。
- 保留现有 `/admin/users`，管理员导航统一提供三个入口。

页面采用后台工作台风格，优先表格、筛选栏、状态 Badge、详情侧栏/对话框和明确的操作按钮，不制作营销型首页。

## 已确认细节

1. 商品关键字匹配名称、品牌和外部 ID，支持分类、商品状态及库存状态筛选。
2. 管理员可见 SKU 精确实物、预占和可售库存，普通用户接口不变。
3. 买家筛选沿用现有管理员订单 API 的 `userId`。
4. 发货成功后刷新当前详情和列表，保留筛选和分页。

## 验收标准

- [ ] 非管理员访问页面被路由拦截，直接调用管理员 API 返回 403。
- [ ] 商品页可稳定分页查看商品及 SKU 信息，不暴露给普通用户。
- [ ] 订单页可按现有管理员接口分页筛选并查看完整详情。
- [ ] 待发货订单可填写快递公司和运单号，提交中防重复，成功后状态更新为待收货。
- [ ] 已发货、已完成、已关闭订单不显示可发货操作。
- [ ] 页面正确处理加载、失败、空数据、提交中和提交失败状态。
- [ ] 不引入商品编辑、订单改价或其他未确认能力。
