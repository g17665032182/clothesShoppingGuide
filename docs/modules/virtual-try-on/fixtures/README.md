## 本地使用

后端 `.env.dev` 已将上述规范化摘要登记到 `TRY_ON_ALLOWED_TEST_IMAGE_SHA256`。开发环境仍只接受白名单命中的图片，不接收任意用户照片。

从服装商品卡进入“我的试穿”，在文件选择器中选择本目录的 `public-model.webp`，点击“上传照片”，再点击“生成试穿图”并确认图像处理说明。

当前验证已通过白名单校验和真实上传，但本地七牛测试域名的 HTTPS 证书与域名不匹配，
导致后台无法下载已上传的照片。配置证书有效、绑定同一私有空间的 HTTPS 下载域名前，
完整生成尚不可用；不要关闭 TLS 校验或将空间改为公开。

请使用原始文件，不要截图、另存为其他格式或重新压缩；这些操作会改变规范化结果，需要重新登记摘要。新图片必须先确认属于合成或有权使用的公开测试素材。

`.env.dev` 的变化需要重启后端才能生效。真实 API Key 仅保存在被 Git 忽略的本地配置中；本目录不存放密钥。
