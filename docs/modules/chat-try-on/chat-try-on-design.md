# 聊天试穿工具设计

## 状态与上下文

- 状态：用户已于 2026-11-12 确认新流程；此前“只生成试穿入口卡片”的方案已作废。
- 业务目的：用户从已开启试穿的商品卡片发起试穿后，聊天工具协调当前商品信息、本人照片和图像生成能力，并将结果交由聊天模型回复前端。
- 所属应用：`apps/web`、`apps/api`。
- 所属模块：`apps/web` 发起用户操作；`chat-records` 编排聊天工具和模型；`product-catalog` 提供当前商品资格；`virtual-try-on` 提供照片、任务和结果能力。详细依赖边界见已确认的技术文档。
- 最后更新：2026-11-12。
- 关联文档：[试穿工具契约](../../contracts/chat-try-on-tool-contract.md)、[AI 虚拟试穿 CRUD 契约](../../contracts/virtual-try-on-crud-contract.md)。
- 需求来源：用户于 2026-11-12 明确要求按以下链路重新设计：商品卡点击试穿、调用试穿工具、传入本人照片、查询商品信息、调用生图大模型、把生成图返回聊天模型并渲染到前端。

## 已确认目标流程

1. 用户点击已开启试穿商品卡上的“试穿”操作。
2. 前端先让用户选择本人照片并明确同意本次图像处理，再以结构化聊天动作提交商品和照片引用；原始照片不进入聊天消息。
3. 服务端确定性地触发试穿工具。工具输入商品 `externalId` 和照片 `photoId`，并从认证上下文取得当前用户；服务端重新查询商品和当前试穿资格，不信任客户端商品快照。
4. 试穿模块校验照片归属、状态、当前同意版本、额度及活动任务，读取本人照片和商品试穿图，调用现有图像生成能力。
5. 生图成功后，生成图作为受控的临时多模态输入交给聊天模型；聊天模型生成文字回复。
6. 后端把最终文字回复与受控的试穿结果引用一并交给前端；前端通过本人任务权限获取并渲染图片。

该流程替代此前“工具只返回入口卡片，用户再进入我的试穿页”的方案。确定性触发工具、复用现有异步任务、将结果图交给同一轮模型并把结果引用绑定到聊天消息的方案，详见已确认的技术文档。

## 范围与边界

### 本次纳入

- 从现有商品卡片发起试穿，不依赖模型从聊天文本猜测商品或自行决定是否触发工具。
- 工具按服务端当前目录事实复核商品启用状态、服装类别、有效颜色和可用商品试穿图片。
- 使用用户明确选择的本人照片；照片归属、状态和用途必须由服务端验证。
- 通过图像生成模型生成试穿图片，将生成结果交给聊天模型，并随聊天回复以受控结果引用交付前端。
- 复用现有试穿照片、任务、存储和结果能力；具体技术边界见已确认的技术文档。

## 明确禁止绕过

- 不接受模型或客户端提供的 `userId`、商品名称/类别/图片事实、供应商凭据、对象键或任务状态作为授权依据。
- 原始照片、Base64、私有存储键、签名 URL、供应商原始错误不得进入普通聊天文本、工具 trace、活动日志或公开历史。
- 点击按钮不等于同意将本人照片交给外部图像模型。必须先让用户明确选择照片并同意本次图像处理。
- 生产真实人像处理仍受供应商留存、处理地区、禁止训练和删除保障审查约束；审查完成前不得启用真实用户照片的外部处理。
- 不得为满足同步聊天体验绕过用户隔离、额度、活动任务、照片删除和结果访问控制。

## 安全与兼容性原则

- 当前商品资格以 `ProductCatalogTryOnPort` 返回值为准；任务创建时继续由服务端再次校验。
- 当前用户从认证上下文获取；照片资产必须验证用户归属、状态、删除状态和允许用途。
- 用户同意必须发生在任何外部图像处理之前，并能审计其适用的处理用途与版本。
- 生成图片通过受控媒体/任务结果通道发送；不把私有对象键或长期公开地址暴露给模型或其他用户。
- 前端商品卡入口使用固定结构，不从 Markdown 或任意工具输出推断图片地址。
- 数据库、HTTP API、任务生命周期和聊天历史的兼容方案已在技术文档中确认，按已批准的实施文档实现。

## 验收清单

- [ ] 点击已启用商品卡的试穿操作，在用户选择照片并明确同意后能确定性地启动对应工具。
- [ ] 服务端拒绝当前未启用、已失资格、无有效服装图片或商品不存在的请求。
- [ ] 只能使用当前登录用户拥有且状态允许的照片。
- [ ] 在外部图像处理前完成明确同意；没有有效同意时不调用图像生成模型。
- [ ] 生图模型收到经授权的最小必要输入；原图和结果不泄漏到普通 trace、日志或无权限历史。
- [ ] 生成结果交给聊天模型处理，并由前端通过受控任务结果引用渲染。
- [ ] 额度、并发任务、超时、失败、重试、删除和访问控制保持明确且有自动化覆盖。
- [ ] 开发/生产环境符合供应商审查和真实人像处理开关约束。
