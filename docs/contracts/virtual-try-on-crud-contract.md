## 范围与权限

启用账号只能访问本人照片、任务、结果和提醒。管理员不拥有跨用户读取、下载或删除权。未登录和禁用账号返回 401，不接受客户端传入 `userId`。

商品事实由商品目录服务端读取。客户端只能提交商品 `externalId`、颜色、照片资产 ID 和同意版本，不能提交 `skuId`、价格、图片 URL、模型 ID、供应商参数、结果地址、额度或任务状态。

## 逻辑资源

### 照片资产

| 字段              | 类型与可空性           | 规则                                                              |
| ----------------- | ---------------------- | ----------------------------------------------------------------- |
| `id`              | UUID                   | 服务端生成                                                        |
| `kind`            | `temporary` 或 `saved` | 临时资产最多绑定一个活动/已结束任务；保存资产可复用               |
| `mimeType`        | 字符串                 | 仅允许 JPEG、PNG、WebP；服务端按文件内容检测                      |
| `byteSize`        | 正整数                 | 服务端从上传内容计算，不信任客户端                                |
| `width`、`height` | 正整数                 | 服务端解码后计算；最长边不超过 4,096 像素                         |
| `createdAt`       | ISO 8601               | 服务端维护                                                        |
| `expiresAt`       | ISO 8601 或 null       | 临时照片未绑定任务时为创建时间加 30 分钟；已绑定或已保存时为 null |
| `deletedAt`       | ISO 8601 或 null       | 删除成功或进入删除终态时记录                                      |

照片响应不返回存储键、公开 URL、Base64 或签名 URL。照片列表只返回用户主动保存的 `saved` 资产摘要。

照片列表额外返回只读 `availability`，供页面提前禁用不可用的上传和生成入口，不改变服务端上传准入规则：

- `disabled`：总开关关闭，或生产环境真实人像开关关闭。
- `test_images_unconfigured`：开发环境已开启，但没有有效的测试图片白名单。
- `test_only`：开发环境仅接受服务端白名单中的测试图片。
- `available`：生产环境两个开关均已开启。开启前仍须满足既定供应商审查要求。

该字段不返回配置值、图片摘要或密钥。读取本人历史、保存照片摘要及删除能力不受此字段限制。前端检查状态期间或检查失败时，不允许上传和生成；服务端继续在每次上传、创建任务时独立校验。

### 试穿任务

| 字段                     | 类型与可空性                              | 规则                                                     |
| ------------------------ | ----------------------------------------- | -------------------------------------------------------- |
| `id`                     | UUID                                      | 服务端生成                                               |
| `status`                 | 枚举                                      | `queued`、`processing`、`succeeded`、`failed`、`deleted` |
| `productExternalId`      | 字符串                                    | 服务端按商品目录规则校验                                 |
| `productName`            | 字符串                                    | 创建时服务端快照                                         |
| `productCategory`        | `tops`、`bottoms`、`dresses`、`outerwear` | 服务端确认，禁止 `shoes`                                 |
| `color`                  | 字符串                                    | 必须匹配当前有效 SKU 颜色                                |
| `garmentImage`           | 对象                                      | 商品颜色图片或主图回退的服务端快照；不接受客户端 URL     |
| `sourcePhotoId`          | UUID 或 null                              | 任务创建时绑定；临时照片完成后解除                       |
| `result`                 | 对象或 null                               | 成功后的私有结果摘要；失败和删除为 null                  |
| `attempts`               | 0–2                                       | 供应商调用次数，最多自动重试一次                         |
| `failureCode`            | 枚举或 null                               | 仅返回稳定业务码，不返回供应商原文                       |
| `consentVersion`         | 字符串                                    | 创建时必须是服务端当前有效版本                           |
| `notificationReadAt`     | ISO 8601 或 null                          | 成功后未读为 null                                        |
| `createdAt`、`updatedAt` | ISO 8601                                  | 服务端维护                                               |
| `completedAt`            | ISO 8601 或 null                          | 成功或最终失败时写入                                     |

结果摘要包含 `resultId`、`createdAt`、`width`、`height` 和可下载能力，不包含永久 URL。结果下载由专用接口返回短期授权或流式响应。

## 输入校验

所有 JSON Body、Query 和 Param 使用所属模块 Zod schema，并通过现有 `StandardSchemaValidationPipe` 绑定；对象默认使用严格对象拒绝未知字段。Swagger DTO 只承担文档元数据。

### 上传照片

`POST /api/try-on/photos` 使用 `multipart/form-data`。Multipart 解析、文件流限制和 Zod/平台适配方式属于技术阶段确认项，但业务规则固定为：

| 字段   | 规则                                                                                                      |
| ------ | --------------------------------------------------------------------------------------------------------- |
| `file` | 必填，JPEG/PNG/WebP 单个图片文件；服务端解码后不超过 10 MiB，最长边不超过 4,096 像素，拒绝动画并清理 EXIF |
| `save` | 布尔值，默认 `false`；仅用户主动选择时创建 `saved`                                                        |

服务端必须依据文件内容重新检测 MIME、大小、像素和可解码性；文件名、扩展名和客户端 `Content-Type` 不能作为唯一依据。上传失败不得产生可访问的半成品照片。未保存且 30 分钟内未绑定任务的临时照片自动过期并清理。

前端选择文件时提前校验声明的 JPEG/PNG/WebP 类型及 1 字节至 10 MiB 大小；非法文件通过 Toast 提示并清空选择，不发起上传。最终内容及动画校验仍由服务端完成。上传失败保留合法文件，便于重试。

### 创建任务

`POST /api/try-on/tasks`

```json
{
  "productExternalId": "string",
  "color": "string",
  "photoId": "uuid",
  "consentVersion": "string"
}
```

- `productExternalId`：trim 后 1–160 字符，拒绝控制字符。
- `color`：trim 后 1–32 字符，拒绝控制字符；比较规则由商品目录端口定义。
- `photoId`：UUID，必须属于当前用户且为可用 `temporary` 或 `saved` 照片。开发渠道只允许合成/公开测试图；取得供应商书面留存、处理地区、禁止训练和删除 SLA 保障前，生产真实人像接入关闭。
- `consentVersion`：trim 后 1–80 字符，必须匹配服务端当前有效版本。
- 未知字段、空字符串、`skuId`、`size`、`model`、`imageUrl`、`userId`、`saveResult` 等均拒绝。

### 列表与查询

`GET /api/try-on/tasks`

Query：

| 参数       | 规则                                 |
| ---------- | ------------------------------------ |
| `page`     | 正整数，默认 1                       |
| `pageSize` | 正整数，默认值和最大值待技术阶段确认 |
| `status`   | 可选状态枚举；`deleted` 默认不返回   |
| `unread`   | 可选布尔值，仅筛选未读完成提醒       |

`GET /api/try-on/tasks/:taskId` 和其他 `:photoId`、`:resultId` 参数必须为 UUID。不存在或越权统一 404。

### 删除与已读

- `DELETE /api/try-on/photos/:photoId`：只允许删除本人 `saved` 照片；临时照片由任务生命周期管理，不能通过此接口绕过任务状态。
- `GET /api/try-on/tasks/:taskId/result`：返回短期下载授权或下载流，不接受任意对象键。
- `DELETE /api/try-on/tasks/:taskId`：只允许删除本人 `succeeded` 结果；标记任务 `deleted` 并安排结果对象删除，重复删除返回当前已删除投影或 404 的具体选择待技术阶段确认。
- `POST /api/try-on/tasks/:taskId/notification-read`：只允许本人把成功任务的未读提醒标记为已读；Body 严格为 `{}`。

## API 提案

全局前缀 `/api`，除登录跳转外均要求启用账号 Bearer JWT。

| 操作           | 方法与路由                                         | 成功响应                                         |
| -------------- | -------------------------------------------------- | ------------------------------------------------ |
| 上传照片       | `POST /api/try-on/photos`                          | 201，照片摘要                                    |
| 列出已保存照片 | `GET /api/try-on/photos`                           | 200，`{ items, availability }`                   |
| 删除已保存照片 | `DELETE /api/try-on/photos/:photoId`               | 204                                              |
| 创建任务       | `POST /api/try-on/tasks`                           | 202，任务摘要，状态 `queued`                     |
| 列出本人任务   | `GET /api/try-on/tasks`                            | 200，分页任务摘要                                |
| 读取任务       | `GET /api/try-on/tasks/:taskId`                    | 200，任务详情和结果摘要                          |
| 下载结果       | `GET /api/try-on/tasks/:taskId/result`             | 200，短期授权或图片流                            |
| 删除结果       | `DELETE /api/try-on/tasks/:taskId`                 | 首次及重复删除均返回 204；不泄露他人资源是否存在 |
| 标记提醒已读   | `POST /api/try-on/tasks/:taskId/notification-read` | 204                                              |

“我的试穿”页面只使用上述本人任务/照片接口。商品卡先调用现有商品目录能力或使用服务端已返回的颜色摘要；创建任务时服务端重新读取商品，不直接相信历史卡片。

## 状态、额度、幂等与并发

- 创建任务成功返回 202，不等待供应商完成；任务 ID 是后台查询和通知的唯一身份。
- 每个用户只能有一个 `queued` 或 `processing` 任务；并发创建返回 409 `ACTIVE_TASK_EXISTS`。
- 每日成功额度为 5，按 `Asia/Shanghai` 自然日 00:00 重置。额度记账必须与成功结果提交在同一事务边界，失败、校验拒绝和供应商最终失败不计次。
- 当额度已用尽返回 409 `DAILY_QUOTA_EXCEEDED`，不创建任务。
- 同一 `photoId` 可以用于多次成功任务；临时照片只可绑定一个未完成任务。
- 创建任务的幂等键是否由客户端提供，或由服务端基于请求指纹/任务表生成，待技术阶段确认。无论方案如何，重试不得绕过活动任务和每日额度。
- 供应商临时错误最多调用两次；最终失败写入 `FAILED` 和稳定 `failureCode`，不扣次数。
- 任务成功必须同时具备结果对象和成功状态；任一持久化失败都按失败/清理流程处理，不返回伪成功。
- 读取、轮询、标记已读和下载不改变每日额度。

## 错误行为

| 状态码 | 业务码/场景                                                                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 400    | 非法 UUID、未知字段、空字符串、非法 multipart、文件类型/大小/像素越界、同意版本格式错误                                                                |
| 401    | 未登录、认证失败、账号已禁用                                                                                                                           |
| 404    | 商品、照片、任务或结果不存在，或不属于当前用户                                                                                                         |
| 409    | `ACTIVE_TASK_EXISTS`、`DAILY_QUOTA_EXCEEDED`、`PRODUCT_NOT_TRYON_SUPPORTED`、`COLOR_UNAVAILABLE`、`CONSENT_REQUIRED`、照片已被占用或任务状态不允许操作 |
| 410    | 结果已删除或短期授权已失效；具体下载语义待技术阶段确认                                                                                                 |
| 413    | 文件超过最终确认的上传限制；若平台统一映射到 400，需在技术文档固定                                                                                     |
| 415    | 媒体类型不支持；若平台统一映射到 400，需在技术文档固定                                                                                                 |
| 503    | 商品图片、对象存储、队列或图像供应商暂不可用；不泄露供应商原始错误                                                                                     |

错误响应只包含稳定的公开业务码、简短中文提示和可选 `taskId`，不包含 SQL、存储键、签名 URL、第三方响应正文、Base64 或密钥。

## 响应投影

任务列表和详情至少公开：

```json
{
  "id": "uuid",
  "status": "queued",
  "product": {
    "externalId": "string",
    "name": "string",
    "category": "outerwear",
    "color": "string",
    "imageUrl": "https://..."
  },
  "result": null,
  "notification": { "unread": false },
  "failureCode": null,
  "createdAt": "2026-11-09T00:00:00.000Z",
  "completedAt": null
}
```

`imageUrl` 仅表示商品目录公开图片的服务端安全投影，不能作为结果对象地址。成功结果的 `result` 只包含尺寸、时间和下载能力；下载必须通过本人任务路由。

## 数据、删除与迁移约束

- 试穿模块至少需要照片资产、任务和结果引用的持久化边界；是否拆成多个 Entity、是否复用通用通知表留到技术阶段。
- 任务保存商品名称、类别、颜色和图片来源快照，避免历史页随目录变化无法解释；不保存尺码、价格或订单信息。
- 输入照片默认不进入长期记忆、聊天消息、模型 trace 或普通日志。
- 用户删除保存照片时只删除该照片；删除结果时保留最小状态以阻止旧下载授权继续使用。
- 对象删除失败需要可重试清理表或等价机制；数据库记录不能在物理对象仍可访问时伪装成已删除。
- 所有新增表、索引、唯一约束和清理任务使用增量 Migration；不使用 `migration:fresh` 验证普通功能。
- 结果永久保存使用 Qiniu 私有 `try-on/` 命名空间且不设置自动过期；下载授权有效期固定为 5 分钟。删除先写数据库墓碑，再由清理任务重试物理删除；技术阶段需补充对象加密和清理告警。
