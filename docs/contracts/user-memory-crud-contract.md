## 资源与字段

- 每位登录用户至多一份自由 Markdown 文档。
- 服装、穿搭及购物长期信息优先，其他背景仅在有助于个性化协作时补充。
- 服务端是权威副本，正文存七牛 Kodo 私有对象，数据库存状态及指针。
- 用户可整份编辑，后台可应用经过校验的精确补丁。
- 不包括游客长期记忆、跨账号共享、历史恢复、向量检索、媒体提取或管理员读取原文。
- 健康、身份、财务敏感信息及密码、Token、API Key 等凭据不得写入。

| 字段                     | 约束                                     |
| ------------------------ | ---------------------------------------- |
| `content`                | UTF-8 Markdown，最多 32 KiB，可为空      |
| `revision`               | 非负整数，成功改变正文时递增             |
| `updatedAt`              | ISO 8601 字符串或 null，沿用当前响应规则 |
| `userId`                 | 仅由认证上下文确定                       |
| 对象键、摘要、generation | 仅服务端使用                             |

不返回对象键、私有签名 URL、Bucket 凭据、服务端路径或任务状态，不在数据库保存正文副本。

## 已确认 API

| 操作     | 方法及路径                      | 输入与响应                                    |
| -------- | ------------------------------- | --------------------------------------------- |
| 读取文档 | `GET /api/memories/document`    | `{ content, revision, updatedAt }`            |
| 替换文档 | `PUT /api/memories/document`    | `{ content, expectedRevision }`；返回最新文档 |
| 清空文档 | `DELETE /api/memories/document` | 无 Body；`204`                                |
| 读取开关 | `GET /api/memories/settings`    | `{ enabled, updatedAt }`                      |
| 修改开关 | `PATCH /api/memories/settings`  | `{ enabled: boolean }`；返回记忆设置          |

原结构化偏好路由移至 `/api/preferences`，本模块不保留其兼容别名。原 settings 接口只控制记忆，前端不得继续将其作为总开关。

### 校验与错误

- Body 使用 Zod strictObject，拒绝未知字段，经 Nest 标准校验 Pipe 绑定。
- expectedRevision 为非负整数；文档按 UTF-8 字节计长，拒绝 NUL、非法 Unicode 和敏感内容。
- 未登录 `401`，非法请求或敏感内容 `400`，revision 冲突 `409`。
- 没有对象且状态有效时返回空文档；已有对象缺失、损坏或存储故障返回 `503`，不伪装为空。
- 接口不接受其他用户 ID；当前用户之外的资源不得泄露存在性。
- 管理员和客服无跨用户读取旁路。
- 返回响应 DTO，不返回 Entity、SQL 或凭据；Swagger DTO 不承担运行时校验。

## 独立设置与提取

- enabled 默认 true，仅控制记忆自动提取与注入；关闭不删除正文或禁止手动管理。
- 开始和应用结果前检查记忆设置，关闭后不提交旧结果。
- 设置写入与文档补丁应用保持同用户互斥。
- 自有任务、调度器、提示、schema、模型调用、重试状态和文档操作结果。
- 提取候选只含 Markdown append/replace/delete，不含结构化偏好 operations。
- 仅保存用户明确表达且稳定的信息，临时、推测和低置信度内容跳过。
- 不保存完整聊天原文、模型推理、原始供应商输出或凭据。
- append 去重；replace/delete 必须唯一匹配目标，不重写全文。
- 对最新正文应用补丁，重复任务和部分成功重试不重复更新。
- 偏好失败不阻止记忆独立运行；记忆失败只重试自己的任务，不改变偏好任务状态。

## 清空、对象与生命周期

- 显式清空递增 generation，即使文档已空，也阻止此前记忆任务回写。
- 只处理记忆任务、文档状态和对象回收，不删除偏好或偏好任务。
- 文档为空时不上传零字节对象，读取立即为空。
- 新对象不可变，上传成功后才事务切换指针；失败不破坏旧版本。
- 无引用旧对象与孤儿对象通过持久化清理队列延迟回收，失败重试。
- 删除来源聊天不自动删除已保存文档。
- 未来物理删除账号时安排对象回收，本次不新增账号删除接口。

## 上下文与安全

- 只生成相关 Markdown 上下文，不查询、拼接结构化偏好。
- 将文档视为不可信参考数据，无相关段落时不注入全文。
- 聊天组合独立来源，当前消息和偏好优先，总预算 512 token。
- 记忆读取失败只跳过记忆，保留可用偏好并继续聊天；日志不含正文和私有签名。
- 预览开启安全过滤，不执行不可信 HTML；409 保留编辑草稿。
- 自动化测试使用 fake 模型及存储，不依赖真实生产凭据或不可控外网。

## 已确认数据与迁移范围

- user_memory_settings 仅作为记忆设置，原值保留；偏好设置由原值独立初始化。
- user_memory_tasks 只处理记忆，user_memory_document_task_results 继续记录文档幂等结果。
- 文档状态、对象回收仍使用 user_memory_document_states、user_memory_document_cleanups。
- 原 user_memories 及结构化结果迁入偏好命名，不再由本模块注册或读写。
- 历史共用任务拆分，保留文档结果和已捕获的 generation，不重新提取完成任务。
- 七牛正文、对象键、revision、摘要和清理记录保持。
- 转换期间暂停旧实例写入和调度，任务关联及恢复细节在技术阶段确认。
- 新增 Migration，审查 SQL、外键和数据转换，不修改历史迁移。
- 本地已按确认的 `pnpm migration:fresh` 完整重建并 Seed；历史数据升级验证在独立测试库执行。
