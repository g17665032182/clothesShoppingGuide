## 字段

| 位置                         | 字段               | 规则                                         |
| ---------------------------- | ------------------ | -------------------------------------------- |
| 商品持久化                   | `tryOnEnabled`     | 必填布尔值，非空，默认 `false`，由管理员设置 |
| 商品持久化                   | `tryOnImageKey`    | 可空私有对象键，仅由管理员上传链路维护       |
| 管理员商品列表和详情         | `tryOnEnabled`     | 返回保存的设置，不以全局配置替代             |
| 管理员商品详情               | `hasTryOnImage`    | 布尔值，不向前端暴露对象存储键               |
| 普通商品查询、分页及聊天卡片 | `tryOnEnabled`     | 布尔值，表示已开启且当前目录资格满足         |
| 试穿公开商品端口             | 试穿设置与资格事实 | 用于服务端重新校验，不依赖客户端快照         |

目录资格要求：有效商品、`tops` / `bottoms` / `dresses` / `outerwear`，
至少一个有效 CNY SKU 颜色，以及按既有安全 URL 规则可用的该颜色图片或商品级试穿图片。
无库存不影响资格；开启时不探测外部图片网络，不调用供应商。商品级图片只作为 SKU 图片的后备。

商品级试穿图由管理员上传，一张图供该商品的所有颜色共用；不覆盖 SKU 图，不与用户人像共用存储目录。
没有任何可用服装图片时管理员不能开启，详情弹框提供上传入口。一期上传后不允许替换或删除。

## 管理员更新

`PATCH /api/admin/product-catalog/products/:id/try-on`

- Bearer JWT，当前账号必须为启用的 `admin`；复用现有认证与角色 Guard。
- Param：严格 UUID `id`。
- Body：严格对象，唯一字段 `tryOnEnabled`，必填且只接受 JSON 布尔值。
- 字符串 `"true"`、数字、`null`、缺字段和未知字段均返回 400，不进行隐式转换。
- Body 与 Param 使用模块内 Zod schema，通过 Nest `StandardSchemaValidationPipe` 绑定。
- 成功返回 200，响应复用管理员商品详情投影，包含保存后的 `tryOnEnabled`。
- 相同值重复请求成功返回当前详情；失败不部分更新商品。
- 设置与更新时间在事务中更新；其他商品、SKU、库存和订单字段不得修改。
- 关闭始终允许；开启必须满足当前目录资格。
- 管理员图片上传接口为 `POST /api/admin/product-catalog/products/:id/try-on-image`，仅接受 multipart 字段 `file`，成功返回 201 管理员详情及 `hasTryOnImage`；预览经同路径 GET 管理员鉴权接口读取 WebP 二进制，设置 `Cache-Control: private, no-store`，不返回私有对象键。
- 上传仅允许 JPEG、PNG、WebP，最大 10 MiB、最长边 4096，拒绝动画；服务端按图片字节解码、剥离 EXIF 并转为 WebP 后存入独立私有 Qiniu 对象目录。
- 上传失败不得修改商品图片状态；数据库失败时补偿删除本次对象。若商品已存在商品级试穿图返回 409，不提供替换或删除。缺图预览返回 404，存储不可用返回 503；文件过大或未知 multipart 字段返回 400。
- 多管理员并发不新增版本字段，最后一次成功提交生效。

| HTTP    | 语义                                                                     |
| ------- | ------------------------------------------------------------------------ |
| 400     | UUID、Body 类型、严格字段校验或图片内容/大小校验失败                     |
| 401     | 未认证、认证失效或账号禁用                                               |
| 403     | 当前账号不是管理员                                                       |
| 404     | 商品不存在                                                               |
| 409     | 开启条件不满足，业务码 `PRODUCT_NOT_TRYON_SUPPORTED`                     |
| 409     | 已存在商品级试穿图片时拒绝再次上传                                       |
| 500/503 | 沿用现有安全错误处理，不返回 SQL、凭据或内部对象；对象存储不可用时不落库 |

GET 管理员列表和详情保持原权限、筛选、分页及库存可见性，仅增加设置字段。
不新增普通用户商品写接口、批量配置、商品编辑或库存修改。

## 任务准入与兼容

- `POST /api/try-on/tasks` 的请求形状保持不变，不接受客户端 `tryOnEnabled`。
- 商品存在但关闭或不具资格时返回 `409 PRODUCT_NOT_TRYON_SUPPORTED`。
- 商品不存在或停用沿用现有不可用商品行为；不泄露内部目录数据。
- 准入拒绝不得创建任务、绑定照片、消耗额度或调用供应商。
- 已接受任务及既有结果沿用原生命周期，不因商品开关关闭而取消或删除。
- 历史展示 schema 缺少字段时默认 `false`，不得丢弃整条历史。
- 读取历史时以当前目录资格校正试穿标记，保留其他历史商品字段。
- 已打开页面不保证实时更新，创建任务始终按当前服务端目录校验。
- 全局可用性、照片白名单、生产人像限制、同意与额度规则继续独立生效。

## 导入、迁移与删除

- 新增非空默认关闭字段，历史行全部初始化为 `false`。
- 导入 JSON v1 不增加此字段，未知字段继续拒绝；新商品使用数据库默认值。
- 更新已有商品时保留管理员设置；资格按最新商品和 SKU 信息计算。
- 导入不接受或覆盖 `tryOnImageKey`；任务采用商品级图片时保存对象键快照，商品图用于所选颜色 SKU 图缺失的后备。
- 测试 Seeder 沿用相同规则，不默认为所有商品开启。
- 增量 Migration 不清库、不重建商品标识、不改变订单与库存。
- 必须在命名的可销毁数据库验证已有数据迁移和新商品默认值，禁止在用户数据库执行 `migration:fresh`。
- 本增量无删除接口。
