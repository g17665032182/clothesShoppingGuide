# 商品试穿开关设计

## 状态与依据

- 状态：原商品开关已实施；商品试穿图片上传增量的设计、技术和实施文档于 2026-11-09 获用户确认，正在实施。
- 更新日期：2026-11-09。
- 用户需求：在商品页面配置每件商品是否可以试穿，只有支持试穿的商品卡展示入口。
- 关联契约：[商品试穿配置 CRUD 契约](../contracts/product-try-on-setting-crud-contract.md)。
- 本文仅调整商品准入与管理入口，不改变已经实现的照片、任务、额度和结果管理。
- 以下默认值、权限、资格与兼容规则已确认；技术与实施阶段分别审批。

## 目标与范围

管理员在现有“商品管理”的商品详情 Dialog 中，配置“支持试穿”开关。
同一商品的所有颜色共享开关，不增加 SKU 级配置，不提供批量操作。
本次只开放试穿配置，不扩展商品名称、价格、库存、上下架或删除操作。

普通用户只能看到符合条件的商品卡入口，不能修改开关。
管理员不因此获得查看其他用户照片或试穿结果的权限。

## 商品准入

1. 商品增加独立布尔设置 `tryOnEnabled`，默认 `false`；存量商品也默认关闭。
2. 只有有效商品且属于上装、下装、连衣裙或外套时允许开启，鞋类不能开启。
3. 至少存在一个有效人民币 SKU 颜色，且可取得合规商品图片，才允许开启。
4. 库存不是试穿准入条件；商品无库存时仍可试穿。
5. 关闭不要求商品仍有效或图片完整，确保管理员随时可以停止后续准入。
6. 后续导入不得覆盖管理员维护的开关；商品或 SKU 状态、图片改变后，实际可试穿资格重新计算。
7. 配置开启不覆盖全局开关、开发图片白名单、生产人像限制、用户额度或同意要求。
8. 商品详情可保存一张商品级试穿图片，供所有颜色共用；它只在所选颜色缺少可用 SKU 图片时作为后备图。
9. 开启时必须至少有一个有效颜色可取得可用图片：可以是该颜色的 SKU 图片，也可以是商品级试穿图片。若没有，管理员先上传图片再开启。
10. 商品级试穿图片由管理员主动上传，不覆盖商品目录导入的 SKU 图片，不与用户人像共用对象目录。
    一期上传后不提供替换或移除入口。

“配置开启”和“当前具备资格”分开：管理员查询展示保存的设置；
普通商品卡返回的 `tryOnEnabled` 表示当前设置和目录资格均满足。
网络可达性与第三方生成能力仍由既有生成流程处理，不在保存开关时请求第三方。

## 管理员交互

- 复用商品详情 Dialog，使用 shadcn-vue Switch 和独立保存按钮。
- 打开详情时读取服务端状态；切换只修改当前表单草稿。
- 不符合开启条件时禁用开启操作，显示对应原因；已有开启设置仍允许关闭。
- 无改动或提交期间禁用保存；提交期间禁用开关，防止重复操作。
- 没有任何可用于试穿的商品图时禁用开关，并在详情中提供商品级试穿图片上传；图片上传成功后刷新详情资格。
- 已有图片显示预览，不提供移除或替换操作；管理员可随时关闭试穿开关。
- 保存成功后更新详情与列表，并用 Sonner Toast 提示。
- 保存失败保留草稿，通过 Toast 提示并允许重试；取消或过期响应不提示。
- 关闭详情或切换商品时丢弃未保存草稿，异步响应不得更新其他商品。
- 普通用户没有配置入口；服务端仍独立校验管理员角色。

## 卡片与任务行为

- 商品搜索、下一页和聊天卡片投影传递当前可试穿标记。
- 卡片仅在标记为 `true` 且符合现有服装品类要求时展示“试穿”。
- 旧快照没有标记时，解析默认关闭，不能使整条历史消息失效。
- 再次读取历史卡片时按当前目录资格校正入口，不改写历史价格、名称或图片快照。
- 管理员修改不实时推送到其他已打开页面；这些页面在重新读取后更新入口。
- 创建任务必须重新读取当前商品设置及资格，不能信任旧卡片、路由参数或客户端布尔值。
- 关闭后拒绝新任务，返回 `409 PRODUCT_NOT_TRYON_SUPPORTED`；不绑定照片、不调用供应商、不消耗额度。
- 关闭前已接受的任务按原流程完成，已有结果继续允许本人查看、下载和删除。

## 数据与边界

商品目录模块维护设置、管理员写入和资格投影；试穿模块通过商品目录公开端口校验。
聊天只使用公开投影，不直接读取商品 Entity；前端不依赖后端内部模型。
新增迁移只增加默认关闭的字段，保留现有商品、SKU、订单和试穿数据。

同一值重复保存视为成功；并发管理员保存按最后一次成功提交生效。
设置变更与商品资格检查应保持一致性。任务准入与关闭并发时，以服务端准入检查先后为边界；
已接受任务不因稍后关闭而取消。

## 验收

- [ ] 管理员能在商品详情保存开关并在刷新后读到相同设置。
- [ ] 存量和新商品默认关闭，重复导入保留管理员设置。
- [ ] 普通用户 403、未认证或禁用账号 401，非法参数或未知字段 400。
- [ ] 鞋类、停用商品、缺少有效颜色或图片的商品不能开启，始终允许关闭。
- [ ] 卡片入口与当前资格一致，旧历史缺字段安全兼容。
- [ ] 历史重新读取后隐藏已关闭入口，旧链接创建任务仍被后端拒绝。
- [ ] 已接受任务与历史结果不受关闭影响。
- [ ] 保存中防重复，失败可重试，成功与失败均通过 Toast 提示。
- [ ] 在可销毁数据库验证增量迁移、权限、状态切换与任务准入。
