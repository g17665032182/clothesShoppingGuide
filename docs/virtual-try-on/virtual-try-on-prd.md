## 问题与目标

用户仅凭服装商品图片难以想象商品穿在自己身上的视觉效果。首版在现有商品卡片提供 AI 试穿入口，用户上传本人照片并选择商品颜色，由图像生成服务生成保留原照片背景和姿势的试穿结果，辅助视觉判断。

试穿图是生成式视觉参考，不是实物预览、尺码建议或合身保证。

## 核心流程

1. 用户在商品卡点击“试穿”；未登录时先登录并返回原商品。
2. 用户选择当前服装商品的颜色；若该颜色缺少 SKU 图片，则使用商品卡主图。
3. 用户上传一张本人照片，或选择此前主动保存的照片；首次使用前阅读并同意第三方处理说明。
4. 用户提交任务。服务端校验账号、每日额度、运行中任务和输入条件，创建后台任务并调用生成服务。
5. 用户可离开页面；“我的试穿”展示待处理、生成中、成功或失败状态。
6. 成功后保存结果并发送站内通知；用户可以查看、下载或删除结果。
7. 默认不保留输入照片；用户显式选择保存时才将输入照片保留供下次复用。任务失败时可重新上传照片重试。
8. 临时服务错误最多自动重试一次；任务最终失败不扣每日次数。

## 范围与非目标

本期范围：商品卡试穿入口、服装颜色选择、本人照片上传和可选保存、第三方处理同意、后台生成任务、个人试穿历史与站内通知、结果下载与删除、每日额度和单任务并发限制。

本期不包含：鞋类试穿、上传任意商品图、多件服装或整套搭配、尺码选择或尺码合身推断、生成模式切换、任务取消、公开分享、浏览器或邮件通知、无限生成或商业计费套餐。

## 已收敛边界与生产阻塞

以下事项按推荐方案收敛；供应商数据处理保障仍是生产接入阻塞项：

- 第三方图像服务是否留存输入照片或生成结果、留存期限、数据处理地区及其隐私条款：当前渠道公开资料不足，渠道凭据仅用于开发环境合成/公开测试图。生产真实人像接入保持关闭，直到取得留存期限、处理地区、禁止训练和删除 SLA 的书面依据。
- 上传照片允许 JPEG、PNG、WebP，服务端解码后限制单文件不超过 10 MiB、最长边不超过 4,096 像素，拒绝动画图片并清理 EXIF；不额外做单人识别硬校验。
- 未选择保存且 30 分钟内未绑定试穿任务的临时上传自动删除。
- 生成结果和主动保存照片使用 Qiniu 私有对象存储的独立 `try-on/` 命名空间；结果不设置过期，下载使用 5 分钟短期授权，删除采用数据库墓碑加可重试物理删除。
- 每日额度按 `Asia/Shanghai` 自然日 00:00 重置。
- 模型供应商与模型 ID 的最终选择：待技术阶段根据接口、安全、数据保留、稳定性、实测延迟及视觉质量确认；当前测速最快模型只是候选。

## 验收标准

- [ ] 用户只能从服装商品卡发起试穿；鞋类及任意商品图不在入口范围。
- [ ] 多颜色商品要求明确选色；选色图缺失时使用商品主图；不出现尺码选择。
- [ ] 仅登录用户可创建任务，任务、结果、照片和通知严格按用户隔离。
- [ ] 第三方处理同意在首次提交前明确展示；未同意不得上传或生成。
- [ ] 默认输入照片在任务结束后删除；显式保存的照片可复用，用户可管理其保存状态。
- [ ] 任务可在后台完成；用户回到“我的试穿”可看到最新状态和结果。
- [ ] 成功结果永久保存、仅本人可见、可下载且可删除；结果提供视觉参考免责声明。
- [ ] 每日 5 次额度、失败不扣次、同账号单个活动任务及每日边界均按确认规则执行。
- [ ] 临时服务失败最多自动重试一次；最终失败不扣次且能清楚展示状态。
- [ ] 站内通知仅对任务所有者可见，不暴露生成结果给他人。
- [ ] 开发渠道只接收合成/公开测试图；没有供应商数据处理书面保障时，生产真实人像接口保持关闭。
- [ ] 未登录点击入口登录后回到原商品；其他既有商品、登录和订单流程不受影响。
