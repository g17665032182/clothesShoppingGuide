# 登录验证码设计文档

## 状态与上下文

- 状态：已实现
- 业务目的：在邮箱密码登录前增加验证码校验，降低自动化登录尝试风险。
- 所属应用和模块：`apps/web` 登录页、`apps/api/src/auth` 认证模块。
- 需求来源：用户确认采用图片验证码，并要求预留第三方验证码入口。
- 最后更新：2026-10-31

## 范围

- 本阶段目标：为登录流程增加图片验证码，并定义后续第三方验证码服务的扩展边界。
- 图片验证码用于登录；注册流程暂不增加验证码。
- 前端需取得并展示验证码图片，提交登录时携带验证码凭据，并支持更换图片。
- 首次进入登录页不请求、不展示验证码图片；用户点击“获取验证码”后才加载图片，获取或刷新成功后开始 60 秒冷却倒计时。登录请求失败后清空已消费的验证码并解除冷却，不自动换图，允许用户立即再次点击获取；本地缺少验证码的校验失败不解除冷却。
- 后端必须在校验邮箱密码前校验验证码；缺失、错误或已失效的验证码不得建立登录会话。
- 设计需允许后续接入第三方验证码服务，不在当前范围内选择或集成具体供应商。
- 明确不包含：短信/邮箱验证码、MFA、登录风控策略、密码找回，以及第三方验证码供应商集成。
- 用户角色：未登录用户可获取挑战并登录；验证码服务端验证挑战，认证模块仅在验证成功后继续登录。

## API 契约

### 获取图片验证码

- 方法与路由：`GET /api/auth/captcha`
- 认证：公开接口。
- 响应：`{ challengeId, imageData, type: 'image' }`，其中 `imageData` 为 SVG data URI，并设置 `Cache-Control: no-store`。
- 错误：生成失败时返回通用服务错误，不泄露验证码答案或内部实现细节。

### 登录

- 方法与路由：`POST /api/auth/login`
- 请求：现有邮箱、密码之外，增加验证码挑战凭据。
- 响应：成功时保持现有 `{ accessToken, user }` 响应和 HttpOnly Refresh Token Cookie 行为不变。
- 错误：验证码缺失、错误、过期或重复使用时拒绝登录；不返回正确答案或过多挑战状态细节。
- 注册、刷新 Token、退出登录和已认证接口行为不变。

## 数据和行为

- 验证码挑战属于短期认证数据，不作为用户业务数据持久化，也不进入用户响应或日志。
- 验证码答案不得由客户端决定或从图片接口响应中明文返回。
- 验证成功后，邮箱密码验证仍按现有认证规则执行；仅两者均成功时创建会话。
- 验证码错误不得改变邮箱密码错误的安全语义，不泄露账号是否存在。
- 验证码挑战有效期为 5 分钟，第一次提交即一次性消费；采用认证模块私有内存存储，单实例部署约束，暂不增加服务端频率限制。
- 验证码 Provider 使用 `svg-captcha` 生成 SVG，保留 Provider/适配器扩展入口；登录接口字段为 `captchaChallengeId` 和 `captchaAnswer`，验证码接口返回 SVG data URI。
- 手动获取或刷新成功后的倒计时为 60 秒；倒计时结束或登录请求失败后允许再次获取，页面卸载时清理计时器并重置页面状态。

## 模块边界

- `apps/web` 登录页面负责呈现挑战、刷新挑战和提交用户输入；验证码请求通过既有 API 层调用。
- `apps/api/src/auth` 负责验证码挑战生命周期及登录前置校验，不把验证码逻辑放入用户模块。
- 验证码校验能力应留有 Provider/适配器扩展入口，使内置图片验证码与未来第三方验证码适配器可在认证流程中替换或组合。
- Provider/适配器扩展点由认证模块拥有；第三方供应商及其前端交互载荷留待未来需求，本阶段不引入供应商依赖。
- 验证码 Provider 不得依赖前端页面实现或用户 Entity。

## 验收清单

- [x] 登录页可获取、展示并更换图片验证码。
- [x] 登录请求携带验证码凭据，服务端先验证验证码再验证邮箱密码。
- [x] 无效验证码不能创建访问令牌、Refresh Token 或登录会话。
- [x] 有效验证码且账号密码正确时，登录响应和跳转行为保持既有契约。
- [x] 验证码答案不出现在接口响应、错误详情或日志中。
- [x] 验证码实现保留第三方 Provider 扩展入口，但本阶段不集成具体第三方服务。
- [x] 有效期 5 分钟、一次性消费、单实例内存存储、不增加服务端频率限制和并发语义已确认。
- [x] 首次进入不加载图片，用户点击获取成功后倒计时 60 秒，页面卸载时清理计时器。
- [x] 验证码错误或其他登录请求失败后停止倒计时，不自动换图，用户可立即手动获取新验证码。
