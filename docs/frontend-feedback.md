# 前端操作反馈

## 组件与入口

- 全局仅在 `apps/web/src/App.vue` 挂载一个 shadcn-vue Sonner Toaster；通过 `vue-sonner` 的 `toast.success()` 显示接口确认后的成功结果。
- 页面通过 `useErrorToast` 监听错误状态。同一错误源在提示可见期间复用 ID，关闭后再次失败使用新 ID，避免快速重试时复用退出动画中的提示；错误状态被自动核实流程清空时，提示保持到用户关闭或超时。
- 不在 Axios 拦截器中增加 Toast，避免一次失败同时由请求层与页面重复提示。
- Toast 使用主题语义变量、中文关闭按钮标签及移动端边距。Dialog 与滚动 Dialog 忽略 Toast 上的外部交互，点击关闭提示时保留弹框和表单内容。

## 状态规则

- 操作错误详情统一由 Toast 显示，删除重复的操作错误横幅。
- 加载失败、版本冲突、结果未知仍保留对应页面状态、草稿和重新读取入口；Toast 消失不代表操作成功。
- 字段校验留在表单，并提供无障碍关联，不监听输入变化反复弹出提示。
- 请求取消、页面卸载及过期响应不产生操作提示；成功提示只在当前账号和相关会话仍有效时发出。登录成功提示在导航完成后显示。
- 下载提示为“已发起试穿结果下载”，不将取得下载地址误报为文件已保存。

## 验证

- `pnpm check`：格式检查、全仓库类型检查、前后端构建。
- 浏览器使用拦截的本地模拟 API 验证资料保存成功与失败、错误重复提交、偏好表单校验、弹框内失败提示、关闭提示保留草稿、保存成功及移动端布局。
- 模拟请求验证不使用真实第三方服务、密钥、人像、购买、支付或删除数据。
