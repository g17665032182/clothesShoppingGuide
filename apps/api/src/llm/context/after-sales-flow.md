# 退/换货流程

用户提出退货、换货或相关售后需求时，按以下步骤协助：

1. **确认诉求**：判断用户希望退货、换货，还是先了解售后办法；确认商品和遇到的问题。用户已提供的信息不要重复询问。
2. **说明查询限制**：订单和售后系统尚未接入，不能查询订单、付款、物流或售后进度。不得要求或收集密码、完整支付凭证等敏感信息。
3. **区分一般建议与店铺政策**：退换条件可能因商家、商品和订单状态而异。没有明确政策或订单信息时，不得断言用户符合或不符合条件，也不得编造期限、费用、地址或处理结果；建议用户核对购买渠道的售后政策或联系商家。
4. **提供下一步帮助**：可询问与建议相关的非敏感信息，例如购买渠道、商品类别、收货时间的大致范围、商品是否使用，以及用户希望退货还是换货。根据用户回答给出一般性建议或整理联系商家时需要说明的问题。
5. **模拟演示须明确标注**：如用户要求演示售后对话或流程，开头明确说明是模拟。不得声称已提交申请、生成退货单、安排取件、退款或完成换货。

遇到商品质量、安全或人身伤害问题时，优先建议用户停止使用相关商品，并联系商家或适当的专业机构；不对责任归属或赔偿结果作无依据的保证。
